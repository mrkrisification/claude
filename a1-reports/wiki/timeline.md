# A1 Group — Timeline of structural events

The spine of the knowledge base: dated, one-line structural events, each linked to
the year note (which carries the report + page citation). Operational detail and
sourcing live in `reports/<year>/overview.md`.

| Year | Event | More |
|------|-------|------|
| 1998 | Full liberalisation of the Austrian telecom market (TKG); incumbent opened to competition | `reports/1998` |
| 2000 | **IPO** (21 Nov) — Vienna + NYSE; "Jet2Web" brand; US-GAAP; UMTS era begins | `reports/2000` |
| 2001 | First CEE mobile move — controlling stake in Si.mobil (Slovenia) | `reports/2001` |
| 2002 | Bought back mobilkom minority from Telecom Italia Mobile; Wireline/Wireless reorg | `reports/2002` |
| 2003 | First dividend; Europe's first national UMTS network launched | `reports/2003` |
| 2004 | Telecom Italia exits; free float ~70%; option to buy MobilTel (Bulgaria) | `reports/2004` |
| 2005 | **MobilTel (Bulgaria) acquired** — largest-ever acquisition by an Austrian company | `reports/2005` |
| 2006 | Footprint ~13 mn customers; Serbia & Macedonia added | `reports/2006` |
| 2007 | **Belarus entry** (velcom/MDC); net debt jumps on debt-funded M&A | `reports/2007` |
| 2008 | **€632 mn Fixed-Net restructuring charge** (civil-servant social plan) | `reports/2008` |
| 2009 | Austrian Fixed Net + Mobile merger approved; convergence push | `reports/2009` |
| 2010 | Austrian fixed+mobile merge into **A1 Telekom Austria** | `reports/2010` |
| 2011 | Group-wide **"A1" brand**; B.net (Croatia) bought; velcom impairment → net loss | `reports/2011` |
| 2012 | **América Móvil** takes a 22.76% stake | `reports/2012` |
| 2013 | **€1.03 bn spectrum auction** (Austria); capex spike; rating cut to BBB- | `reports/2013` |
| 2014 | **América Móvil becomes majority owner**; capital increase; blizoo + one.Vip (Macedonia) | `reports/2014` |
| 2015 | Recovery (+6.7% EBITDA); largest-ever fibre/LTE programme; Amis acquired | `reports/2015` |
| 2016 | Convergence bolt-ons (Atlant Telecom/Belarus); EBITDA label reverts to plain "EBITDA" | `reports/2016` |
| 2017 | **A1 Digital** founded (IoT + cloud/ICT); fibre + data centres | `reports/2017` |
| 2018 | Group-wide rebranding | `reports/2018` |
| 2019 | **IFRS 16 adopted** (EBITDA basis change; EBITDAaL introduced); 5G spectrum | `reports/2019` |
| 2020 | **COVID-19**; **5G launches in Austria** (Jan); ESG/climate targets | `reports/2020` |
| 2021 | 5G + fibre build-out; Croatia spectrum; dividend raised | `reports/2021` |
| 2022 | Rebrand to **"A1 Group"**; revenue+EBITDA growth in tough macro; 5G monetisation | `reports/2022` |
| 2023 | **Spin-off of EuroTeleSites** (tower business) | `reports/2023` |
| 2024 | First full post-spin-off year (depreciation up, EBIT down); Austria 52% of revenue | `reports/2024` |
| 2025 | Record revenue €5,577 mn; Belarus dividend restrictions persist; Austria 49% | `reports/2025` |

## The four defining structural events
1. **2000 IPO** — state monopoly → listed company.
2. **2005 MobilTel** — pivot to a CEE mobile-led group.
3. **2014 América Móvil control** — current ownership structure.
4. **2023 EuroTeleSites spin-off** — tower carve-out reshaping post-2023 EBIT/depreciation.
